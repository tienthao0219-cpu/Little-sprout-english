# Little Sprout English
Website lớp tiếng Anh của Miss Thảo. Xem HUONG-DAN.md để cài đặt.

- `index.html`, `css/`, `js/`: giao diện (web tĩnh, không cần build)
- `data/manifest.json`: danh mục giáo trình, unit, app
- `apps/`: nơi chứa file HTML của app/game
- `apps-script/Code.gs`: máy chủ lưu dữ liệu (dán vào Google Apps Script)
- `docs/lse-report.js`: đoạn mã cho app mới muốn báo kết quả
